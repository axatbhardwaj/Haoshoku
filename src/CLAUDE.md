# src/

## Subdirectories

| Directory     | What                              | When to read                              |
| ------------- | --------------------------------- | ----------------------------------------- |
| `common/`     | Shared utilities (logging, shell) | Adding utility functions, debugging       |
| `helpers/`    | Standalone helper scripts         | Adding Git config, SSH setup              |
| `os_scripts/` | OS-specific setup scripts         | Adding OS support, modifying setup logic  |
