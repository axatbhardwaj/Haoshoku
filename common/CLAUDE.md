# common/

## Files

| File                   | What                          | When to read                              |
| ---------------------- | ----------------------------- | ----------------------------------------- |
| `paru_applist.txt`     | Repo/AUR packages for Arch    | Adding/removing Arch packages             |
| `paru_applist_iobox.txt` | Repo/AUR packages for the iobox profile | Adding/removing iobox packages |
| `flatpacks_arch.txt`   | Flatpak apps for Arch         | Adding/removing Flatpak applications      |
| `omarchy-plugins.json` | Omarchy plugin manifest with optional `disableOnInstall` | Editing the default plugin set or replacing stock widgets |
