# Hyprland Parity Gap

Tracking the KDE shortcuts that did **not** translate to Hyprland binds during the v4.6 hyperland-port. Generated by `bun haoshoku.js --hyprland-keybinds`, which emits `# UNTRANSLATED: ...` comments inline in `configs/hypr/conf.d/20-keybinds.conf` for every KDE action without a Hyprland equivalent.

## Summary

- **Translated:** 79 binds (workspace nav, window management, audio, brightness, media, screenshots, lock, log out, custom service launchers, full Krohnkite tiling suite, Sleep / Hibernate / PowerOff).
- **Untranslated:** 39 entries (~33.6%) — concepts that don't exist in Hyprland or are owned by the Caelestia Quickshell shell.
- **Duplicates:** 5 (multiple services bound to the same key — first wins; rest commented).

These translate cleanly; nothing below is a bug. The remaining 39 are listed here so future-you can decide which (if any) to hand-fill into `~/.config/hypr-ocean/conf.d/92-user.conf`.

## Untranslated by category

### Plasma shell (17) — Caelestia / Quickshell owns or no equivalent

| Action | KDE binding | Why untranslated |
|---|---|---|
| `activate application launcher` | `Meta` | Caelestia's Quickshell launcher already owns SUPER. |
| `activate task manager entry 1-9` | `Meta+1` .. `Meta+9` | Caelestia likely uses these for workspace switching; binding them as task-manager activations would clash. |
| `next activity` / `previous activity` / `manage activities` | `Meta+A` / `Meta+Shift+A` / `Meta+Q` | KDE Activities don't exist in Hyprland. Closest hack: special workspaces — semantically different, would confuse muscle memory. |
| `show dashboard` | `Ctrl+F12` | KDE Dashboard widget; no Hyprland counterpart. |
| `clipboard_action` / `show-on-mouse-pos` | `Meta+Ctrl+X` / `Meta+V` | KDE clipboard popup at cursor. `cliphist` + `wofi` can approximate but UX differs. |
| `cycle-panels` | `Meta+Alt+P` | KDE panel switching; Caelestia has a single Quickshell bar. |

**Fill manually if you miss:** clipboard at cursor — `cliphist list \| wofi --dmenu \| cliphist decode \| wl-copy`. Add to `92-user.conf`.

### KWin desktop effects (12)

| Action | KDE binding | Why untranslated |
|---|---|---|
| `Expose` / `ExposeAll` / `ExposeClass` | `Ctrl+F9` / `F10` / `F7` | KDE Desktop Effects. Hyprland has the [hyprtasking](https://github.com/raybbian/hyprtasking) plugin for similar overview UX — not built-in. |
| `Overview` | `Meta+W` | Caelestia ships its own overview surface via Quickshell. |
| `Edit Tiles` | `Meta+T` | KDE 6 tile editor; Hyprland uses static layouts (dwindle/master). |
| `Window Operations Menu` | `Alt+F3` | KWin's right-click-titlebar menu; no built-in Hyprland equivalent. |
| `MoveMouseToCenter` / `MoveMouseToFocus` | `Meta+F6` / `Meta+F5` | KWin accessibility scripts. `ydotool mousemove ...` could approximate. |
| `view_zoom_in` / `view_zoom_out` / `view_actual_size` | `Meta++` / `Meta+-` / `Meta+0` | KWin zoom filter. Hyprland exposes `cursor:zoom_factor` and has a `zoom_factor` keyword you can `hyprctl keyword` toggle. |
| `disableInputCapture` | `Meta+Shift+Esc` | KDE input-grab override; rarely needed. |

**Fill manually if you miss:** Overview — install hyprtasking plugin and bind `dispatch overview` to `SUPER, W`. Zoom — `bind = SUPER, plus, exec, hyprctl keyword cursor:zoom_factor 2.0`.

### Activity manager (3)

| Action | KDE binding | Why untranslated |
|---|---|---|
| `switch-to-activity-...` (Gaming, Flux, Function) | `Meta+F1` / `F2` / `F3` | KDE Activities concept doesn't exist in Hyprland. Could be approximated with named special workspaces. |

### Keyboard layout switcher (2)

| Action | KDE binding | Why untranslated |
|---|---|---|
| `Switch to Last-Used Keyboard Layout` | `Meta+Alt+L` | Hyprland: `bind = SUPER_ALT, L, exec, hyprctl switchxkblayout current next` — but requires knowing layout names. |
| `Switch to Next Keyboard Layout` | `Meta+Alt+K` | Same as above. |

**Fill manually if you miss:** `bind = SUPER_ALT, K, exec, hyprctl switchxkblayout current next` in `92-user.conf` once you've checked `hyprctl devices` for the keyboard ID.

### Microphone volume (2)

| Action | KDE binding | Why untranslated |
|---|---|---|
| `increase_microphone_volume` | `Microphone Volume Up` | No physical `XF86MicVolumeUp` keysym exists on standard laptops. Only `XF86AudioMicMute` (toggle) is real. |
| `decrease_microphone_volume` | `Microphone Volume Down` | Same — no keysym. |

**Workaround:** bind something else to `wpctl set-volume @DEFAULT_AUDIO_SOURCE@ 5%+/-`. E.g. `bind = SUPER_SHIFT, F1, exec, wpctl set-volume @DEFAULT_AUDIO_SOURCE@ 5%+`.

|---|---|---|

## How to fill specific gaps

The Ocean overlay sources `~/.config/hypr-ocean/conf.d/*.conf` in lexical order. Drop your overrides in `92-user.conf` (numbered after our generated files so they take precedence).

```bash
mkdir -p ~/.config/hypr-ocean/conf.d
cat > ~/.config/hypr-ocean/conf.d/92-user.conf <<'EOF'
# My hand-filled bindings for items not in the auto-translator
bind = SUPER_ALT, K, exec, hyprctl switchxkblayout current next
bind = SUPER, V, exec, cliphist list | wofi --dmenu | cliphist decode | wl-copy
EOF
hyprctl reload
```

Then commit your additions back with `bun haoshoku.js --hyprland-backup` so they persist into the haoshoku repo.

## Regenerating this list

Whenever your KDE shortcuts change, re-translate:

```bash
bun haoshoku.js --hyprland-keybinds
grep '^# UNTRANSLATED' configs/hypr/conf.d/20-keybinds.conf | sort
```

The `# UNTRANSLATED:` comments embed the action name, section, and binding — enough context to either extend `KDE_TO_HYPRLAND_ACTIONS` in `src/helpers/configure_hyprland.js` (if you find a clean mapping) or hand-fill in `92-user.conf` (if you don't).
