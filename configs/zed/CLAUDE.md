# configs/zed/

Zed editor configuration (sanitized backup without API keys).

## Files

| File            | What                         | When to read                              |
| --------------- | ---------------------------- | ----------------------------------------- |
| `settings.json` | Editor settings and options  | Modifying Zed behavior or appearance      |
| `keymap.json`   | Custom keybindings           | Modifying keyboard shortcuts              |

## Subdirectories

| Directory | What                        | When to read                              |
| --------- | --------------------------- | ----------------------------------------- |
| `themes/` | Custom color themes         | Adding or modifying Zed themes            |
